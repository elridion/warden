# Offering cup model

`greek_cup.obj` / `greek_cup.fbx` — from [The Base Mesh](https://www.thebasemesh.com/model-library),
released under [CC0](https://creativecommons.org/publicdomain/zero/1.0/). Attribution is not required;
credited here and in the mod README anyway.

`greek_cup.obj` is embedded into `Warden.dll` at build time (see `Warden.csproj`) and loaded by
`src/ObjLoader.cs`. The FBX is kept as the source file.
